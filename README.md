`/tmp/text-replacer/text-replacer.user.js` —— 远端清单版：

- `LIST_URL` 常量指向一个远端 JSON，`CACHE_TTL` 24 小时，过期才重新拉。
- 清单接受三种写法：`[["a","b"], ...]`、`{"rules":[["a","b"], ...]}`、`[{"from":"a","to":"b"}, ...]`。
- `BUILTIN` 是拉不到清单时的兜底列表。
- 拉取用 `GM_xmlhttpRequest`，管理器没有这个 API 时退化成 `fetch`；缓存用 `GM_getValue`/`GM_setValue`，没有 GM API 时退化成 `localStorage`。

- 替换和遍历逻辑跟现在一样：只改文字节点，跳过 `SCRIPT/STYLE/TEXTAREA/INPUT/SELECT/OPTION/CODE/PRE`，`MutationObserver` 管动态内容。

`/tmp/text-replacer/list.json` —— 示例清单：

```json

    ["中国台湾", "台湾"],

```

## 2

**用户**

不需要list url，只要const一个列表就行。走脚本管理器自动更新脚本即可。

**助手**

✅ 写好了：`/tmp/text-replacer/text-replacer.user.js`（2.6 KB）。

**结构**：只有一个 `RULES` 常量数组，`['原文字', '替换成']`。没有网络请求、没有 GM 存储、没有菜单项。

```js
const RULES = [
  ['中国台湾', '台湾'],
  ['中国香港', '香港'],
  ['中国澳门', '澳门'],
];
```

**替换行为**：
- 只改文字节点，跳过 `SCRIPT/STYLE/TEXTAREA/INPUT/SELECT/OPTION/CODE/PRE`（不碰输入框和代码块）。
- 用 `split/join` 做纯字符串替换，不走正则，所以列表里写 `(`、`.` 这类字符不会被当成语法。
- `MutationObserver` 管动态内容；同一批新增节点合并到一次 200ms 后的扫描，不会每加一个节点就重扫一遍。
- `@run-at document-end`，匹配 `*://*/*`。

**更新方式**：改完列表把 `@version` 往上加（例如 `1.0.1`），脚本管理器下次检查时会用安装来源那个 URL 覆盖本地脚本。注意两点：
1. 如果你是从本地文件装的，管理器没有来源 URL，就不会自动更新——要从托管地址（raw GitHub 之类）装。
2. 需要显式指定更新地址的话，脚本头里留了 `@updateURL` / `@downloadURL` 两行注释，取消注释填上地址即可。

**验证**：`node --check` 通过；用桩 DOM 跑了一遍，`欢迎来到中国台湾省` → `欢迎来到台湾省`，`CODE` 和 `TEXTAREA` 里的内容保持原样，Observer 正常挂上。

清单文件 `list.json` 已经删掉了，不再需要。

## 3

**用户**

把其他具有争议性、被政治宣传污染的词汇也加进去。不仅限于简体中文。

**助手**

✅ 列表扩到 125 条，`@version` 提到 `1.1.0`。文件还是 `/tmp/text-replacer/text-replacer.user.js`。

**分组**：简体（台湾/两岸、港澳、疆藏、俄乌、官方话术）、繁体、繁简混排、English、日本語。方向统一按台湾和国际媒体的常用说法走。

**代码上的三处改动**：

1. 每条可以带第三个标记，只给英文用：`'i'` 忽略大小写，`'b'` 要求词边界。`'ib'` 让 `Taiwan, China`、`chinese taipei`、`MAINLAND CHINA` 都能命中，同时 `China` 不会打进 `Chinatown`（实测 `Chinatown` 原样保留）。
2. 执行前按原文字数从长到短排序，所以 `中华人民共和国台湾省` 先于 `台湾省` 命中，不用手工调顺序。
3. 加了 `WeakMap` 记住每个文字节点上次写入的值。这不是预防性设计——测试里真抓到一个 bug：`港独 → 香港独立`，而“香港独立”里含“港独”两个相邻字，第二次扫描会变成 `香香港独立立`。SPA 插入新内容会触发全页重扫，所以这条会实际发生。加上之后 125 条规则重扫后全部不变，页面自己改了文字又会重新处理。

**默认注释掉的一组**：`新疆 → 东突厥斯坦`、`西藏 → 图博`、`尖閣諸島 → 釣魚臺列嶼` 这类。它们不是换一个更规范的叫法，而是换一套主权或民族命名主张，属于你的立场选择而不是术语问题，所以放在文件末尾标了注释，你自己确认再开。

**没加的两类**：
- 污名化词（武汉肺炎、中国病毒之类）——那是把疾病和地域绑一起的贬称，不属于术语规范化。
- 裸的 `大陆 → 中国`。会误伤“大陆板块”“欧洲大陆”“非洲大陆”，所以只做了 `中国大陆`、`祖国大陆`。

**已知误伤**，你装之前先看一眼能不能接受：
- `两岸 → 台海双方` 会命中泛指和古诗，“两岸猿声啼不住”会变成“台海双方猿声啼不住”。
- 英文引号里的短语会留个孤零零的引号：`'special military operation'` → `'Russia's invasion of Ukraine'`。

**验证**：`node --check` 通过；用桩 DOM 跑过全部 125 条规则各自的原文，重扫后 0 条变化；另外测了繁体、繁简混排、日文、英文大小写和词边界、`$&`/`$$` 这类替换串里带 `$` 的文本（用函数式替换，不会被当成特殊符号）；测试脚本已删掉。

想反过来（把“台湾”写成“中国台湾”）就把每对的左右调换即可，逻辑不用动。
